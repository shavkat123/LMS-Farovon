# Таблицы ИИ-экзаменатора: создание без ручных кликов

В схеме экзамена **15 таблиц и 174 столбца**, из них 34 подстановки и 24 набора выбора
(раздел 3.2 методички `МЕТОДИЧКА-СЕРТИФИКАЦИЯ-НАСТАВНИКОВ.md`). Руками в конструкторе это
несколько дней и почти гарантированные опечатки в логических именах — а они потом молча
ломают Web API и FetchXML, потому что портал ищет столбец, которого нет.

Поэтому схема описана данными (`exam-schema.json`), а создаётся автоматически.

## Рабочий путь: решение + `pac`

```powershell
cd C:\Users\fid920251715\Desktop\LMS-farovon\tools\exam

# 1) собрать решение (локально, ничего не меняет)
python build-exam-solution.py --out C:\tmp\exam-solution.zip

# 2) импортировать
pac solution import --path C:\tmp\exam-solution.zip --publish-changes
```

Сначала лучше прогнать **пилот на одной таблице** — если Dataverse чем-то недоволен,
это видно за минуту и без мусора в среде:

```powershell
python build-exam-solution.py --only new_aiprompt --out C:\tmp\exam-pilot.zip
pac solution import --path C:\tmp\exam-pilot.zip --publish-changes
```

XML не пишется с нуля. За образец берётся **уже работающая таблица этой же среды**
(`new_trajectory` из выгрузки решения `LMS`): из неё переносятся системные столбцы, формы,
представления и лента — в них меняются только имена и выдаются новые идентификаторы.
Пользовательские столбцы генерируются из схемы. Так исключается класс ошибок «Dataverse не
принял структуру»: структура взята у таблицы, которая в этой среде уже живёт.

Образец нужен как файл: `pac solution export --name LMS --path C:\tmp\solref`.
Путь к нему задаётся ключом `--ref` (по умолчанию `C:\tmp\solref\LMS.zip`).

## Почему не через API метаданных

`create-exam-tables.ps1` делает то же самое вызовами метаданных Dataverse — это удобнее
(понятные ошибки по каждому столбцу, идемпотентность). **В этом тенанте он не работает:**
политика условного доступа отклоняет вход по коду устройства (ошибка **53003**, устройство
не зарегистрировано) — проверено на двух публичных клиентах, Dynamics 365 и Azure CLI.
Другие способы получить токен закрыты: на машине включён ConstrainedLanguage, поэтому
локальный веб-сервер для обычного входа через браузер поднять нельзя.

Скрипт оставлен: он пригодится в среде без такой политики или если для автоматизации заведут
регистрацию приложения (вход по секрету политику условного доступа не проходит вовсе —
она применяется к пользователям, а не к приложениям).

## Что важно знать

- **Значения наборов выбора** идут подряд от `100000000` в том порядке, в каком перечислены
  в `exam-schema.json`. На эти числа ссылаются константы в потоках и шаблонах — порядок
  вариантов менять нельзя, только дописывать в конец.
- **Имена наборов записей** (то, что идёт в `/_api/…`) — логическое имя плюс `s`:
  `new_exams`, `new_examattempts`, `new_examquestions`, `new_certifications` и так далее.
- **Столбцы дат** (`new_issuedon`, `new_validuntil`, `new_certvaliduntil`) создаются с
  поведением «Местное время пользователя» и форматом «только дата». Переключить поведение
  на «Только дата» можно в конструкторе, обратно — нельзя, поэтому решается это осознанно
  и после того, как станет видно, как даты показываются на портале.
- **Повторный импорт** того же решения обновляет таблицы, а не плодит их. Но удалённые
  из схемы столбцы импорт не удаляет — их убирают вручную.

## Чего это НЕ делает

Это только схема данных. Дальше остаётся:

1. **Права на таблицы портала** — Power Pages не видит таблицу, пока для неё нет
   Table Permission с нужной областью и ролями. Чем это грозит, видно из истории:
   16.09.2026 у сайта осталось 2 права из 21, и портал отвечал 403 на девять таблиц.
2. **Настройки Web API** — `Webapi/<таблица>/enabled` и **явный список полей**
   (`Webapi/<таблица>/fields`). Wildcard `*` запрещён с 14.09.2026, а запрос без
   `$select` отбивается как «все столбцы».
3. **Потоки Power Automate** — 13 потоков из раздела 3.4 методички.
4. **Страницы портала** — раздел 3.6.

Первые два пункта делаются в этом же репозитории: права — в `table-permissions/`,
настройки — в `sitesetting.yml`, заливка через `pac pages upload`.
