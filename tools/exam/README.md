# Таблицы ИИ-экзаменатора: создание скриптом

В схеме экзамена **15 таблиц и 174 столбца**, из них 34 подстановки и 24 набора выбора
(раздел 3.2 методички `МЕТОДИЧКА-СЕРТИФИКАЦИЯ-НАСТАВНИКОВ.md`). Руками в конструкторе это
несколько дней и почти гарантированные опечатки в логических именах — а они потом молча
ломают Web API и FetchXML, потому что портал ищет столбец, которого нет.

Поэтому схема описана данными (`exam-schema.json`), а создаёт её скрипт.

## Файлы

| Файл | Что это |
|---|---|
| `exam-schema.json` | Описание таблиц и столбцов: тип, длина, варианты выбора, цель подстановки |
| `create-exam-tables.ps1` | Создаёт всё это в Dataverse вызовами метаданных |

## Как запускать

Сначала — сухой прогон. Он ничего не меняет, только показывает список того, что будет создано:

```powershell
cd C:\Users\fid920251715\Desktop\LMS-farovon\tools\exam
.\create-exam-tables.ps1
```

Скрипт напечатает код устройства и ссылку — нужно войти тем же аккаунтом, под которым вы
работаете со средой. Никаких модулей ставить не нужно.

Если список устраивает — создаём:

```powershell
.\create-exam-tables.ps1 -Apply
```

Займёт около 10 минут: примерно 200 вызовов, каждый по паре секунд.

## Что важно знать

- **Скрипт идемпотентен.** Перед созданием каждого объекта он проверяет, нет ли его уже.
  Упало на середине — исправьте причину и запустите снова, дубликатов не будет.
- **Порядок не случайный:** сначала все таблицы, потом обычные столбцы, потом подстановки.
  Цель подстановки должна существовать, иначе связь не создаётся; по этой же причине
  самоссылка `new_examquestion.new_parentquestion` создаётся на третьем шаге.
- **Ошибки пишутся в `create-exam-tables.errors.txt`** рядом со скриптом, с полным телом
  ответа Dataverse — по нему видно, какой именно атрибут не понравился.
- Всё создаётся в решении **LMS Exam** (`LMSExam`), издатель — общий для среды, префикс `new`.
- Значения наборов выбора идут подряд от `100000000` в том порядке, в каком перечислены
  в `exam-schema.json`. В коде потоков и шаблонов на эти числа ссылаются константы —
  порядок вариантов менять нельзя, только добавлять в конец.

## Чего скрипт НЕ делает

Это только схема данных. После неё остаётся:

1. **Права на таблицы портала** — Power Pages не видит таблицу, пока для неё нет
   Table Permission с нужной областью и ролями. Живой пример, чем это грозит:
   16.09.2026 у сайта осталось 2 права из 21, и портал отвечал 403 на девять таблиц.
2. **Настройки Web API** — `Webapi/<таблица>/enabled` и **явный список полей**
   (`Webapi/<таблица>/fields`). Wildcard `*` запрещён с 14.09.2026, а запрос без
   `$select` теперь отбивается как «все столбцы».
3. **Потоки Power Automate** — 13 потоков из раздела 3.4 методички.
4. **Страницы портала** — раздел 3.6.

Первые два пункта делаются в этом же репозитории: права — в `table-permissions/`,
настройки — в `sitesetting.yml`, заливка через `pac pages upload`.
