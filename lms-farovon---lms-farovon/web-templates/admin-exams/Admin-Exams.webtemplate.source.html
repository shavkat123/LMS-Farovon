{% comment %} Admin Exams — список экзаменов аттестации и создание нового (/admin/exams). Доступ только у роли «Аттестация: администратор». Общий админский гейт (HR, Наставник и т.д.) здесь нельзя: наставники как раз сдают этот экзамен. Данные тянем на клиенте через Web API (общий include Exam Admin Common, window.ExamAdm): после создания экзамена страница уходит на настройку, а список должен быть свежим без кеша. Счётчики (уроки, одобренные вопросы, попытки, сертификаты) считаются в браузере по минимальным выборкам — по одному полю связи с экзаменом, до 5000 строк на таблицу. Удаления нет нигде: у роли нет права удалять экзамены. Один экзамен — один цикл аттестации. Для нового цикла экзамен копируется: уроки с текстом, одобренные вопросы и правила переходят в новый черновик, а попытки, результаты, сертификаты, задания ИИ и журнал остаются у прошлого. Новый экзамен всегда создаётся черновиком: поток публикации срабатывает только на смену статуса, и экзамен, созданный сразу опубликованным, остался бы без снимка вопросов. {% endcomment %} {% assign ex_is_admin = false %} {% if user and user.roles contains 'Аттестация: администратор' %}{% assign ex_is_admin = true %}{% endif %} {% unless ex_is_admin %}
