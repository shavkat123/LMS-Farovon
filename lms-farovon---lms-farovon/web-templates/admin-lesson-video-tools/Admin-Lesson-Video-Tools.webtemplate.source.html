{% comment %} Admin Lesson Video Tools — замена видео урока и удаление урока на админ-экранах. Подключается include'ом ВНУТРИ ролевого гейта экрана (сейчас: Admin Library, Admin Course Form). Урок — запись new_h5pcontent, его видео — .h5p-файл в столбце new_h5pfile. «Заменить видео» перезаписывает только файл: id урока не меняется, поэтому название, обложка, курс, порядок и прогресс сотрудников остаются за уроком. Новый файл берётся с диска или копируется у другого материала библиотеки (из Dataverse, а если там его нет — оригинал из SharePoint через Flow). Разметка экрана: кнопки data-lv-action = replace | delete | show, data-lv-id, data-lv-name, data-lv-type (текущий new_librarytype), data-lv-active = 1 | 0 строка data-lv-row = id урока — после операции правится на месте, без перезагрузки (нужно там, где рядом несохранённая форма); контейнер строк — data-lv-list, его текст на случай, когда строк не осталось, — data-lv-empty. Без data-lv-row страница просто перезагружается. {% endcomment %}
Видео урока

Заменить видео

Меняется только файл урока. Название, описание, обложка, курс, порядок и прогресс сотрудников остаются прежними.
Удаление урока

Удалить урок?

Урок исчезнет из каталога и программы курса, его файл удалится. Отменить удаление нельзя.

Если урок ещё может понадобиться — скройте его: сотрудники перестанут его видеть, а файл и прогресс сохранятся.
