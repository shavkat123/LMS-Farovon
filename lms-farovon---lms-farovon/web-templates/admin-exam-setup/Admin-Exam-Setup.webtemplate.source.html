Уроки
Вопросы создаются из текста озвучки урока. У каждого урока экзамена должен быть текст — иначе публикация не пройдёт. Удалить урок нельзя, поэтому лишние уроки не добавляйте.
Как получить текст, если урок только озвучен

Если урок озвучен, а текста нет:

  1. загрузить видео урока в SharePoint;
  2. открыть его в Stream и включить расшифровку;
  3. скачать файл VTT или DOCX;
  4. загрузить этот файл сюда (кнопка «Загрузить текст курса»).

Файл всего курса (DOCX) страница сама разобьёт на уроки по начальным фразам уроков и покажет разбивку — её нужно проверить перед сохранением.

Раскладка билета

Сколько заданий каждого урока, типа и уровня попадёт в билет, и хватает ли для этого одобренных вопросов. В ячейке: заданий в билете → одобрено в банке / нужно. Пересчитывается сразу при изменении параметров и весов уроков.

Создание вопросов ИИ

ИИ пишет вопросы по тексту урока, другой промпт их проверяет; в банк попадают только одобренные. Задание нельзя отменить или изменить со страницы — при неудаче создаётся новое.
