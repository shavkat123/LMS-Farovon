{% comment %} Exam Admin Common — общее для четырёх страниц администратора аттестации: /admin/exams, /admin/exam-setup, /admin/exam-bank, /admin/exam-results. Подключается include'ом ВНУТРИ ролевого гейта «Аттестация: администратор» — вне гейта здесь нечего показывать. Даёт: - window.ExamAdm: запросы к Web API портала, названия значений наборов выбора, форматирование дат и чисел, всплывающие сообщения и окна подтверждения, опрос состояния, выгрузку CSV, раскладку билета «урок × тип × сложность» (методичка 7.3) и параметры экзамена по умолчанию; - стили .exad-* поверх общих примитивов .adm-* из customtheme.css. Значения наборов выбора идут от 100000000 в порядке из tools/exam/exam-schema.json. Порядок менять нельзя — только дописывать в конец. {% endcomment %}
