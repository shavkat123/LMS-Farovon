{% comment %} Аттестация — точка входа участника (/certification). Что здесь есть: условия экзамена, история попыток, действующий сертификат и кнопка «Начать». Чего здесь нет намеренно: никаких подсчётов. Страница только создаёт запись попытки — всё остальное (сборка билета, проверки допуска, статусы) делают потоки. Если поток откажет в допуске, он сам напишет причину в попытку, и мы её покажем. Данные тянем на клиенте через Web API, а не Liquid/FetchXML: страница должна обновлять состояние после создания попытки без перезагрузки. {% endcomment %}
