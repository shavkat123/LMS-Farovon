# Power Automate — потоки портала

## Оформить покупку награды (`d4142c4e-38a5-f111-b8de-000d3adcd7a2`)

Триггер «When Power Pages calls a flow», вход `rewardItemId` (ключ `text`), выходы
`ok / message / balance / stock`. Вызывается из Rewards-Shop через
`/_api/cloudflow/v1.0/trigger/<guid>` (form-urlencoded, поле `eventData`).

`Оформить-покупку-награды.flow.json` — эталонное определение (из экспорта решения
LMSfarovon после правки 2026-08-31). Если поток править в конструкторе — после сохранения
экспортировать решение заново и обновить файл, иначе репозиторий соврёт.

`fix-flow.js` — скрипт, которым определение чинили: пустая схема триггера, вложенные циклы,
пробелы в лукапах, пустой остаток, типы выходов. Пригодится как образец, если придётся
править определение снова: экспорт → распаковать в C:\tmp\flow-src → node fix-flow.js →
Compress-Archive → импорт решения.

`stock = -1` в ответе = награда без лимита (пустой `new_stock`).
